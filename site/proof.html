We attack our own model

Proof: code checks every line.

We give Gemma a hard case on purpose. We ask it several times, with a fresh seed each time. Our checks look at every answer. This page shows what Gemma wrote each time, which check blocked it, and whether it reached a viewer.

Run it live

Try your own caption

Write something a video might say. Gemma 4 31B on AMD Token Factory makes the easy-read, Hindi, Italian, Spanish, French and Portuguese captions live, and our checks test every answer. Nothing you write is stored.

3 to 45 words. Try a number, a "not", or a name: those are what the checks guard.

Describe a picture

Choose a picture. Gemma 4 31B on AMD Token Factory lists what it can see, then writes one description line, as if the picture stayed on screen for a short silent pause. Our description rules check the line, and Gemma repairs what fails. Your picture is sent once and never stored.
