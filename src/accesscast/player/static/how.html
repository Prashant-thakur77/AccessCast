How it works · one clip, step by step

From one video to five.

Every step below shows the real output for one clip. Nothing on this page was written by hand.

  1. 1Listen

    Whisper writes down every word. A second model pins each word to the moment it is said.

    • 2Find the pauses

      A description has to fit between the words, so the code measures every pause.

    • 3Look

      Gemma 4 31B, on AMD, looks at still frames from the scene and lists only what it can see. Each fact names its frames.

      • 4Write

        Gemma writes one line from that list, and nothing else, inside a word budget.

      • 5Check

        Code checks the line, rule by rule. The model never decides whether its own line is good enough.

      • 6Repair

        The line goes back to Gemma with the exact rule it broke. Then the code checks the new line again.

        1. 7Fit it in

          A line is spoken in a pause. Where there is no pause, the extended version holds the picture while it is read.

        2. 8A person decides

          Every description line waits for a person. They see the frames, the checks and every repair, then approve, edit or reject it. Nothing is published while a line is waiting.

        3. 9Every way to watch

          The same analysis makes every version, so they never disagree.
